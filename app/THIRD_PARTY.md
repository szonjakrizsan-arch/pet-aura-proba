# Third-party components
- Celestine 0.2.1 (MIT) - astronomical calculations, bundled in js/vendor/celestine.js, license: js/vendor/LICENSE.celestine
- tz-lookup 6.1.25 (CC0-1.0) - timezone from coordinates, bundled in js/vendor/tzlookup.js
- City data (data/cities.json): derived from GeoNames (https://www.geonames.org, CC BY 4.0) via the all-the-cities package (MIT, data/LICENSE.all-the-cities). Attribution required: "City data © GeoNames, CC BY 4.0".
- Additional Hungarian settlements in data/cities.json (all 3,155 Hungarian settlements, e.g. small villages such as Oszkó): coordinates averaged from the GeoNames postal code dataset (https://download.geonames.org/export/zip/, CC BY 4.0), obtained via the symerio/postal-codes-data redistribution (data CC BY 4.0). Attribution: "City data © GeoNames, CC BY 4.0" (shown under the birth-place field).
